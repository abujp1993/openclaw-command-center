# Features Guide

## Task Management

### Creating Tasks

1. Press **Ctrl+Shift+T** or click **Add Task**
2. Enter title and optional description
3. Set priority (Low/Medium/High)
4. Add due date if needed
5. Select categories

### Task Features

- **Subtasks**: Click the expand icon to add subtasks
- **Inline Edit**: Double-click task title to edit
- **Quick Complete**: Click checkbox to mark done
- **In Progress**: Click play button to mark as working

### Filtering

- Use the filter buttons (All/High/Medium/Low)
- Search by title or description
- Toggle completed tasks visibility

---

## AI Chat

### Starting a Conversation

1. Go to Chat (Ctrl+3)
2. Select AI provider from dropdown
3. Type your message
4. Press Enter to send

### Features

- **Streaming**: See responses as they're generated
- **Code Blocks**: Syntax-highlighted code with copy button
- **Conversation History**: All chats are saved locally
- **Multiple Providers**: Switch between Claude, OpenAI, Ollama

### Tips

- Use Shift+Enter for new lines
- Click Stop to cancel generation
- Create new conversation for different topics

---

## Notes

### Creating Notes

1. Go to Notes (Ctrl+2)
2. Click **New Note**
3. Write in Markdown format

### Markdown Support

```markdown
# Heading 1
## Heading 2

**bold** and *italic*

- Bullet list
- Another item

1. Numbered list
2. Second item

`inline code`

​```javascript
// Code block
console.log("Hello");
​```
```

### Organization

- Create folders for organization
- Add tags to notes
- Link notes to tasks
- Use search to find anything

---

## Command Palette

Press **Ctrl+K** to open.

### Available Commands

- **Navigation**: Go to Tasks, Notes, Chat, Settings
- **Create**: New Task, New Note, New Conversation
- **Toggle**: Sidebar, Theme
- **Search**: Find notes, Find tasks

### Tips

- Type to filter commands
- Use arrow keys to navigate
- Press Enter to execute
- Press Escape to close
